EYA · Quartier polygon labEXPERIMENTAL

Google-POI-driven road-ownership corrections proposal for the 310 quartiers of Cotonou + Abomey-Calavi. Base ownership is the water-aware 700 m-buffer road propagation from the IGN chef-lieux; the Metro v2 layer sits on top and shows automatic reassignments (with chef-lieu protection, connectivity invariant, and equal-split frontier rules). None of these are authoritative. Read README.md for details.

Use the drawing controls at the top-left of the map to trace what a quartier should look like.
① Type the quartier name BELOW first, ② click the polygon tool, ③ trace, ④ double-click to finish.
Repeat for each quartier. Use Download to export all drawn polygons as one GeoJSON file.
